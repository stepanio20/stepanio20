# Рынок нумизматики — и телеграм-радар для Katz Auction

Отраслевой ресёрч + продуктовое предложение. Дата: 11.08.2026, данные 2024–2026.
Полная дизайн-версия: `Katz_Numismatic_Report.pdf` рядом. Бот: **@KatzCoinsBot** (код в `../`).

## Резюме

- Рынок коллекционных монет: **$11,87 млрд (2025) → $23,87 млрд к 2032, CAGR 10,5%**
  (консервативные оценки $5–10 млрд); капитализация всех коллекций — $300+ млрд.
- У Katz — уникальный актив: **открытый JSON API с реализованными ценами ~520 тыс. лотов
  с 2020 года** (за такие данные CoinArchives берёт $600/год).
- Ниша пуста: **ни один аукционный дом не имеет телеграм-бота** с алертами и историей проходов.
- В отличие от «бриллиантового» кейса — никаких чужих чатов: данные публичны и принадлежат
  дому-партнёру. Юридический риск минимален.
- **MVP собран и запущен в этой же сессии**: онбординг RU/EN, радар-алерты, живой поиск по
  520k лотов, история цен, лид-форма консигнации, тарифы в Telegram Stars.

## 1. Рынок

Обороты домов (2024–2025): Heritage $2,15 млрд общий / $470+ млн нумизматика; Stack's Bowers
$325 млн; Künker €10,9 млн за день; SINCONA ~CHF 9,7 млн за неделю (8 из топ-10 рекордов
русских монет); CNG feature-аукцион $4,2 млн; eBay-категория монет $1+ млрд/год.

Рекорды: 1933 Double Eagle — $18,87 млн; рубль Иоанна Антоновича 1740 — €2,97 млн;
25 рублей Николая II 1896 — $480 тыс. Индексы: PCGS3000 +1,1%/год за 25 лет против
+4,8%/год у Key Dates & Rarities — выбор «не тех» монет — главный риск покупателя, отсюда
ценность истории проходов. Золото $2 900→$4 300/oz (2025): премии на рядовой материал
расплавились, но буллион-покупатели конвертируются в коллекционеров. Ядро роста — 30–45 лет,
онлайн — крупнейший канал.

## 2. Katz Auction

Прага (Opletalova 1284/37), KATZ Bros s.r.o., с 2007 (Стас Кац), старт с eBay/MA-Shops.
Специализация: Россия, Австро-Венгрия, Восточная Европа, античка, Китай; монеты + банкноты +
фалеристика (50 категорий). Ритм: ~3 аукциона/2 недели (Coins 2000–2800 лотов → Gold 110–200 →
Paper Money), ~5 000 лотов/2 нед, sell-through 30–55%. Экономика: buyer's premium 24%
(gold — 10%), seller 5%, выплата 30 дней, все лоты с €5, эстимейтов нет. Языки EN/DE/CS/RU.
**Нет приложения, нет телеграм-канала, retention — только email** — это и есть дыра, которую
закрывает бот.

## 3. Конкуренты и подписки

Платят уже сейчас: CoinArchives Pro **$600/год**; PCGS Collectors Club $69/$149/$249;
NGC $25/$149/$299; Greysheet ~$240–350/год + CDN API от $95/мес; Numista ~€55–60/год;
грейдинг $23–80+/монета. Боты-аналоги: Fragment Auction Alerts ~176k MAU; eBay-снайперы;
sneaker-мониторы $9,99/$24,99/$99,99 за 10/50/∞ слотов — платят за **скорость и слоты**.
Ни у одного аукционного дома или агрегатора (Sixbid/NumisBids/Biddr) телеграм-бота нет.

## 4. Данные и API Katz (проверено ~25 живыми запросами)

- `GET /api/v1.0/auction` — реестр аукционов (статусы created/prebidding/waiting_room/live/
  paused/completed; псевдо-аукционы id≤0 исключать).
- `GET /api/v1.0/lot` — лоты: `auction_id`, `search` (полнотекст по всей базе), `display=48`,
  фильтры категорий/стран/золото/серебро/cert, сортировки; пагинация `{items, pages, results}`.
- `GET /api/v1.0/lot/<id>` — деталь (+ ending_time и др.); `GET /options?...` — справочники.
- Поля: title/description/country(ISO)/category/фото(Bunny CDN `?width=N`)/start_price(€5)/
  `context.highest_bid`/`sold_price`+`status`. Год/металл/грейд — регулярками из текста.
  Эстимейтов и числа ставок нет. Числа приходят строками; даты — naive ISO (Прага).
- Объёмы: ~520k лотов, ~205 завершённых аукционов; полная выкачка ≈ 11k запросов (3 ч при 1 rps).
- Вежливость (в парсере): 1 rps, ретраи на 5xx, активные аукционы раз в 30 мин, архив immutable,
  «мягкие 404» (HTTP 200 + HTML) детектить по контенту; правильная цель — прямой фид от Katz.
- Обогащение: спот золота/серебра (melt value), Numista (поле numista_id есть), CDN API опц.

## 5. Выполнимость и право

- Данные: публичный API партнёра, персданных нет → GDPR-контур только по нашим юзерам.
- B2C-платежи: **только Telegram Stars** (digital goods); подписки `subscription_period=2592000`
  (единственное значение, 30 дней) с автопродлением; потолок ~2500 Stars; годовые — разовым
  инвойсом; вывод через Fragment→TON (нетто ~$0,013/Star, холд 21 день, мин. 1000).
- RU-аудитория: Stars покупаются за рубли (СБП/реселлеры) — монетизация закрыта выбором рельса.
- B2B (Dealer-годовой €290, retainer дома) — счётом в фиате/USDT вне Telegram, легально.
- Антиспам: только opt-in, ≤3 пуша/день вне live, отписка кнопкой.

## 6. Продукт: @KatzCoinsBot (собран)

«Радар аукционов Katz в твоём Telegram: скажи, что собираешь, — бот поймает нужный лот среди
5 000 новых за месяц, напомнит до закрытия и покажет, за сколько такое реально уходило».

Модули MVP: онбординг RU/EN с интересами; `/watch` (ключевые слова + потолок цены) с алертами
появления и закрытия; `/find` и `/price` — живой поиск/история по всей базе Katz; `/auctions`;
`/sell` — лид консигнации админам; `/pro` — Stars-инвойсы с автопродлением; админка
(`/stats`, `/broadcast`, `/refresh`); вежливый парсер по расписанию.

Тарифы: Free (3 слота) · **Pro 299⭐/мес** (~$5,99: 25 слотов, 24ч/1ч, история) ·
**Sniper+ 749⭐** (безлимит, 10 мин до закрытия, фид непроданных, CSV) ·
**Dealer 1900⭐ или €290/год** (аналитика спроса, 30 фото-оценок/мес, приоритетная консигнация).
Плюс разовая оценка 150⭐ (sendPaidMedia), годовые −20%, аффилиатка Bot API 8.1 (20–30%).

Воронка: мгновенная ценность на онбординге («в Auction 209 — 17 лотов по твоим интересам») →
пейволл на 4-м слоте → FOMO «ушёл ниже, Sniper+ узнал бы раньше» (≤1/нед) → событийный оффер
перед premium-аукционом → win-back 50% → рефералка «месяц Pro за друга».

B2B-ценность дома: bid-напоминания дают +1–2% к финальным ценам ≈ **€5–20k/мес** при GMV
€0,5–1 млн/мес (больше всей B2C-выручки на старте); лиды консигнации; карта спроса из
сохранённых поисков; retention вместо одного email. Правильная модель — гибрид: Stars-подписки +
**B2B-retainer €500–1500/мес** или rev-share.

## 7. Дорожная карта, экономика, Дубай, риски

Фазы: **0 (сделано)** — MVP запущен · **1 (2–4 нед)** — партнёрство с Katz (фид/white-label),
полная выкачка архива, QR в каталогах/рассылке, телеграм-канал · **2 (+1–2 мес)** — пейволлы,
триал 7 дней, фото-оценка, портфель · **3 (+3–6 мес)** — Дубай + мульти-фид («нумизматический
Bloomberg», Katz — якорь).

Экономика (нетто; микс 70/25/5, ARPPU ~$6,4, churn 12%, LTV ~$45–55): 1k MAU/2% → ~$8k/год
с retainer; 5k/3% → ~$24k; 20k/4% → ~$80–95k. Break-even B2C — 60–100 платящих.

Дубай: ОАЭ — №2 золотой хаб мира (~15% мировой торговли, AED 625 млрд оборот 2024);
VAT 0% на инвестметаллы ≥99% (коллекционные — 5%); до ~500k россиян с 2022 и +13k
миллионеров-резидентов за 2024; локальные игроки (Numisbing, House of Coin) слабы в онлайне;
точка входа — The Currency Fair (сент. 2026); голд-аукционы Katz (10%) — родной продукт для
буллион-аудитории.

Риски: зависимость от одного дома (мульти-фид архитектура, контракт сразу); обход Stars = бан
(не делаем); конверсия ниже прогноза (модель держится на B2B); вывод через TON (регулярность,
учёт ЕС); Cloudflare (вежливость + прямой фид).

**Вердикт: GO — и уже в проде.** Прибыльная ниша с потолком $100–300k/год на одном доме и
опцией масштабирования через мульти-фид; не венчурная ракета. Успех решают: формализованное
партнёрство с Katz, дисциплина алертов, скорость закрепления в нише.
