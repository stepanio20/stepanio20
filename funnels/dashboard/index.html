Connect PostHog for all-users analytics (5 min)

This dashboard shows this browser's events (great for QA/demo). For real, all-users funnel data across everyone you send traffic to, drop a PostHog key in funnels/shared/config.js and build this funnel in PostHog:

  1. 1️⃣ funnel_view — landed on the funnel
  2. 2️⃣ quiz_start — tapped Start
  3. 3️⃣ quiz_complete — finished all questions
  4. 4️⃣ lead — gave email ← your cost-per-lead
  5. 5️⃣ offer_view — saw the paywall
  6. 6️⃣ checkout_start — hit buy ← your conversion

Every event carries variant so you can break the funnel down by v1–v5 automatically.
